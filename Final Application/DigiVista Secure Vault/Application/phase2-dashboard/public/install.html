Install DigiVista Secure Vault

Add the secure dashboard to your phone. Vault passwords remain handled by Vaultwarden and are not stored in this installation page.

Android

  1. Open this page in Chrome.
  2. Tap the browser menu (⋮).
  3. Choose Install app or Add to Home screen.
  4. Confirm Install.

iPhone / iPad

  1. Open this page in Safari.
  2. Tap the Share button.
  3. Choose Add to Home Screen.
  4. Tap Add.

Open secure dashboard

Security note: offline caching is limited to the public dashboard shell. Vault logins, passwords and API responses are excluded.
